# Reborn Field Guide

A companion tool for Pokémon Reborn. It covers type matchups, a Pokédex with movesets and catch locations, every trainer battle with full teams, wild encounters by area, and a world map with toggleable layers.

See `PLAN.md` for scope and `data/SCHEMA.md` for the data contract.

The data comes from the [Pokémon Reborn Database](https://github.com/Andrew-Foote/reborn-db-site) by Andrew Foote, which was extracted from the game files of Reborn v19.16.
